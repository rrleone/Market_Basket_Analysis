# Dados

Os arquivos brutos do dataset Instacart Market Basket Analysis não são armazenados neste repositório devido ao tamanho dos dados.

Para executar o notebook integralmente, disponibilize nesta pasta:

- `aisles.csv`
- `departments.csv`
- `orders.csv`
- `products.csv`
- `order_products__prior.csv`
- `order_products__train.csv`

O arquivo `order_products__prior.csv` é especialmente grande e é utilizado como principal base transacional da análise.
